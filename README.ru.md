**Your quiet AI partner, in every conversation**
(Ваш тихий ИИ-партнер в любом разговоре)

Polymath сидит рядом и помогает, когда не хватает слов или знаний. Он слышит, что говорит собеседник, видит, что у вас на экране и подсказывает, что делать дальше. Больше никто его не видит и он никогда не говорит за вас.

### Зачем он нужен

- **Общение с людьми, чей язык вы не знаете.** Polymath слушает собеседника и показывает, что он сказал, а затем подсказывает, что ответить на языке собеседника и на вашем родном (чтобы вы всегда понимали, что именно говорите собеседнику). Вы остаетесь в разговоре сами, а не прячетесь за переводчиком.
- **Онлайн-знакомства.** Polymath может следить за вашим экраном и подсказывать, как ответить на языке собеседника и на вашем родном (чтобы вы всегда понимали, что именно пишете собеседнику). Вы пишете сообщение, которое звучит как вы, только лучше.
- **Флирт.** Получайте идею для ответа, шутку или комплимент ровно в тот момент, когда она нужна.
- **Повседневные задачи.** Задайте вопрос, сделайте скриншот экрана с помощью приложения и получите ответ, который подходит именно вашей ситуации.
- **Сложные и непонятные вещи.** Не знаете, куда нажать или почему что-то не работает? Покажите экран Polymath и он укажет на ошибку и подскажет, как ее исправить.

---

Небольшая панель-помощник для разговоров и встреч. Она слушает собеседника и переводит его речь на ваш язык, подсказывает ответ на нужном языке, решает задачу с экрана и отвечает на любые вопросы в чате.

**Панель видна только вам.** При показе экрана в Zoom, Teams, Meet, Discord, OBS, на скриншотах и записи экрана её нет.

## Возможности

- **Listen** (`7` / `Ctrl` + `Alt` + `7`). Слушает звук компьютера (голос собеседника в созвоне), распознаёт фразы, показывает перевод на ваш родной язык и, когда к вам обращаются, готовый ответ на языке разговора с переводом. Клик по ответу копирует его. Режим «Только когда нужен ответ» показывает лишь реплики, на которые надо ответить.
- **Screenshot** (`2` / `Ctrl` + `Alt` + `2`). Снимок экрана уходит модели: решение задачи, ответ на вопрос из теста, разбор кода.
- **Watch** (`4` / `Ctrl` + `Alt` + `4`). Следит за экраном и отвечает, когда на нём появляется новый вопрос или задача. Отключается сам через 10 минут.
- **Чат**. Обычные вопросы. Цифра в начале выбирает команду: `1` Quick (кратко, быстрая модель), `3` Answer (ответ на последний услышанный вопрос с учётом разговора), `5` Translate (перевод).
- Модель видит последние фразы разговора, поэтому в чате можно спросить «как ответить на его последний вопрос?».
- **База знаний**. Ваши файлы `.txt` и `.md` с готовыми ответами на частые вопросы. Подходящий ответ из них находится на компьютере, без интернета, и показывается сразу, пока модель ещё отвечает.

## Установка

Готовые файлы лежат в папке `dist`:

- `Polymath-Setup-<версия>.exe` - установщик, язык выбирается по языку Windows, поддерживается 22 языка: можно выбрать папку, не нужны права администратора, ярлыки на рабочем столе и в меню «Пуск», запуск программы после установки;

Windows SmartScreen может предупредить о неизвестном издателе (файл не подписан). Нажмите «Подробнее» и «Выполнить в любом случае».

Требования: Windows 10 версии 2004 (май 2020) или новее, Windows 11. На более старых системах скрытие от захвата экрана не работает.

## Первый запуск

1. Откройте настройки (шестерёнка на панели).
2. Выберите провайдера модели и вставьте ключ API, нажмите «Сохранить ключ». Ссылка «Где взять ключ» ведёт на страницу провайдера.
3. Нажмите «Проверить подключение». Появится список доступных моделей, клик по модели подставит её в поле.
4. Укажите родной язык. В разделе «База знаний» в поле «О вас» коротко опишите себя (профессия, опыт). Модель учтёт это в ответах.
5. Нажмите «Сохранить» (или Ctrl+S).

### Провайдеры

| Провайдер                 | Модель по умолчанию   | Картинки (Screenshot/Watch) | Звук напрямую |
| ------------------------- | --------------------- | ----------------------- | ------------- |
| Google Gemini             | gemini-flash-lite-latest | да                      | да            |
| OpenAI                    | gpt-5-mini            | да                      | нет           |
| Anthropic Claude          | claude-sonnet-5-5     | да                      | нет           |
| OpenRouter                | openrouter/auto       | да                      | нет           |
| Groq                      | openai/gpt-oss-120b   | нет                     | нет           |
| Mistral                   | mistral-medium-latest | да                      | нет           |
| Ollama (локально)         | llama3.2              | нет                     | нет           |
| Свой (OpenAI-совместимый) | любая                 | зависит от модели       | нет           |

Названия моделей у провайдеров меняются. Если модель не найдена, нажмите «Проверить подключение» и выберите модель из списка.

«Быстрая модель» используется командами Quick и Translate. Её можно оставить пустой, тогда работает основная.

Если модель ответила 503 (перегружена) или 429 (кончилась квота), программа сразу спрашивает вторую модель из пары.

### Резервная модель

Раздел «Резервная модель» в настройках: другой провайдер, которого программа спрашивает, когда обе модели выше ответили 503 или 429. Например, Anthropic Claude (по умолчанию `claude-haiku-5-5`, быстрая). Ключ для резерва хранится отдельно. Если его нет, берётся ключ того же провайдера из раздела «Модель». Резерв пропускается, если он не умеет читать то, что отправляется: картинку экрана (Screenshot/Watch) или звук.

## Распознавание речи (для Listen)

В настройках «Распознавание речи» четыре способа:

1. **Через модель** (по умолчанию). Фраза отправляется прямо в чат-модель. Работает с Google Gemini, ключ тот же.
2. **Облачный Whisper API**. OpenAI (`whisper-1`, `gpt-4o-mini-transcribe`), Groq (`whisper-large-v3-turbo`, быстро и дёшево) или свой OpenAI-совместимый сервер. Ключ для распознавания хранится отдельно от ключа модели.
3. **Локально (whisper.cpp)**. Звук не покидает компьютер. Установка одной командой:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-whisper.ps1
```

В установленной программе скрипт лежит в `<папка программы>\resources\scripts`. Параметры: `-Model tiny|base|small|medium|large-v3-turbo` (по умолчанию small, 466 МБ) и `-Cuda` для видеокарт NVIDIA. Файлы ставятся в `%APPDATA%\Polymath\whisper`. Затем выберите «Локально» и нажмите «Проверить распознавание».

4. **Локально (NVIDIA Parakeet)**. Тоже на этом компьютере, на процессоре быстрее whisper.cpp и обычно точнее. Модель `parakeet-tdt-0.6b-v3` знает 25 европейских языков (английский, русский, украинский, немецкий, французский, испанский и другие), но не турецкий и не китайский. Работает через [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx). Кнопка «Скачать Parakeet» в настройках ставит всё на место, или одна команда:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-parakeet.ps1
```

Всего около 520 МБ. Параметр `-Model v2` берёт модель только для английского, в английском чуть точнее. Файлы ставятся в `%APPDATA%\Polymath\parakeet`. Затем выберите «Локально (NVIDIA Parakeet)» и нажмите «Проверить распознавание». Первая фраза после паузы ждёт 7-10 с, пока загружается модель, следующие занимают меньше секунды. После 10 минут без речи сервер останавливается и освобождает память. Обе загрузки (программа и модель) проверяются по SHA-256, который публикует GitHub. Файл, который не совпал, удаляется и ничего не устанавливается. Без опубликованного хеша установки нет.

При первом запуске на новом компьютере панель один раз спрашивает, как распознавать речь: через Gemini (ничего скачивать не нужно) или Parakeet на этом компьютере (приложение скачает около 520 МБ, с ходом загрузки и кнопкой отмены). Ответ можно потом изменить в настройках.

Кнопка «Проверить распознавание» есть для всех четырёх способов.

### Короткие и длинные команды

Короткие команды работают внутри панели, длинные (с `Ctrl` + `Alt`) работают из любого окна. Цифра в пустом поле выбирает команду, также работает `1 ваш текст`.

| Действие | Короткая (в панели) | Длинная (из любого окна) |
| --- | --- | --- |
| Быстрый ответ (коротко, быстрая модель) | `1` | `Ctrl` + `Alt` + `1` |
| Решить задачу с экрана | `2` | `Ctrl` + `Alt` + `2` |
| Ответ на только что услышанный вопрос | `3` | `Ctrl` + `Alt` + `3` |
| Следить за экраном (вкл/выкл) | `4` | `Ctrl` + `Alt` + `4` |
| Перевод | `5` | `Ctrl` + `Alt` + `5` |
| Слушать звонок (вкл/выкл) | `7` | `Ctrl` + `Alt` + `7` |
| Показать / скрыть панель | `Esc` | `Ctrl` + `Alt` + `P` |
| Нажимать сквозь панель (вкл/выкл) | - | `Ctrl` + `Alt` + `T` |
| Настройки | `Ctrl` + `,` | `Ctrl` + `,` |
| Новый разговор | `Ctrl` + `N` | - |
| Остановить ответ | `Ctrl` + `.` | - |
| Показать все горячие клавиши | `F1` | - |

**Панель скрыта?** Нажмите `Ctrl` + `Alt` + `P` (или сочетание из настроек) либо запустите Polymath ещё раз (ярлык в меню Пуск), и панель вернётся. Значок в трее по умолчанию выключен. Кнопка `?` в панели (рядом с настройками, или `F1`) показывает все команды и горячие клавиши.

**Важно:** короткие команды работают только когда активно поле ввода, и не работают в режиме сквозного нажатия. Длинные команды (с `Ctrl` + `Alt`) работают всегда.

Горячие клавиши меняются в настройках: щёлкните поле и нажмите нужное сочетание. Если сочетание занято другой программой, панель напишет об этом.

Панель перетаскивается за заголовок, её место запоминается. Ширина, прозрачность и размер шрифта настраиваются.

### Внешний вид и мышь

Раздел «Интерфейс» в настройках:

- **Тема** - тёмная (графит, по умолчанию) или светлая (слоновая кость);
- **Непрозрачность панели** - вся панель вместе с текстом (30-100%);
- **Непрозрачность фона** - только фон панели, текст остаётся чётким (20-100%);
- **Нажимать сквозь панель** - щелчки проходят через панель подсказок в окно под ней. Панель нельзя двигать и нажимать мышью, клавиатура и горячие клавиши работают. Включается и выключается сочетанием `Ctrl` + `Alt` + `T`, в заголовке панели тогда видна отметка «сквозь». Окно настроек всегда обычное;
- **Нажимать кнопку наведением** - если задержать курсор на кнопке панели (по умолчанию 3 секунды, можно 1.5-5), она нажмётся сама. Под кнопкой заполняется полоска. Работает и в режиме «сквозь панель».

Listen захватывает звук всей системы. Используйте наушники: тогда в запись попадает только собеседник, а не ваш голос.

## Свои команды

Цифровые команды хранятся в `%APPDATA%\Polymath\commands.json` (кнопка «Открыть commands.json» в настройках). Файл перечитывается при каждом вызове, перезапуск не нужен. Пример:

```json
{
  "1": {
    "name": "Interview",
    "instructions": "Answer as a senior Java developer at a job interview. Answer in {conversation_language}, then give a short translation into {native}.",
    "model": "main"
  }
}
```

Поля: `name`, `instructions` (обязательны), `model` (`main` или `small`), `screen: true` (приложить снимок экрана), `watch: true` (следить за экраном), `listen: true` (включить Listen). Подстановки: `{native}` - ваш язык, `{conversation_language}` - язык разговора.

## Насколько надёжно скрытие

Окна создаются с `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`. Это системный механизм Windows: при захвате экрана на месте окна видно то, что под ним. Его уважают Zoom, Teams, Google Meet в браузере, Discord, OBS, «Ножницы», PrintScreen и Xbox Game Bar.

Кроме того:

- нет кнопки на панели задач и в Alt+Tab;
- значок в трее выключен по умолчанию (трей виден при показе всего экрана);
- нет системных всплывающих окон: подсказки, списки и меню нарисованы внутри панели, контекстное меню отключено.

Ограничения:

- Скрытие не защищает от камеры, направленной на монитор, и от аппаратного захвата HDMI.
- Если вы показываете **окно** программы (не весь экран), а панель лежит поверх него, собеседник увидит то, что под панелью. Это нормально.
- Windows старее 10 версии 2004 вместо панели показывает в захвате чёрный прямоугольник.
- Открытые ссылки и файлы (commands.json, папка данных) открываются в обычных программах и видны при показе экрана.

Проверить скрытие на своём компьютере:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\verify-capture.ps1
```

Скрипт показывает два защищённых тестовых окна и одно обычное, снимает экран двумя способами и пишет результат. Строка `RESULT: Polymath windows are hidden from screen capture` значит, что всё работает.

## База знаний

Раздел «База знаний» в настройках:

- **О вас** - общая информация о вас. Модель учитывает её во всех ответах.
- **Файлы** - кнопка «Добавить файлы» или перетаскивание `.txt` и `.md` в раздел. Файлы копируются в `%APPDATA%\Polymath\knowledge` (кнопка «Открыть папку»). Там их можно править, программа перечитает изменения сама. Файл с тем же именем заменяется, размер до 2 МБ, кодировка UTF-8, UTF-16 или Windows-1251.
- **Использовать базу знаний в ответах** - включается, когда в базе есть хотя бы один файл.
- **Показывать найденное в базе сразу, до ответа модели** - так же.

Как это работает. На вопрос в чате и на каждую фразу собеседника в Listen программа сначала ищет ответ в ваших файлах, без интернета и без модели. Найденный фрагмент сразу появляется синим блоком «Из базы знаний» над ответом модели, кнопка «Копировать» рядом. Одновременно модель получает эти данные (всю базу, если она небольшая, иначе найденные фрагменты) и отвечает, опираясь на них. Поиск понимает разные формы слова («зарплата» и «зарплату»). Вопрос на другом языке локальный поиск не найдёт, но модель всё равно ответит по базе.

Как писать файлы, любой из трёх способов:

```markdown
# Какую зарплату вы ожидаете?
От 300 000 ₽ на руки, готов обсуждать.

# Почему уходите с текущей работы?
Хочу больше задач по архитектуре.
```

```text
В: Когда сможете выйти?
О: Через две недели.

Q: What is your notice period?
A: Two weeks.
```

Или просто абзацы через пустую строку: первая короткая строка абзаца считается темой.

## История и экспорт

Раздел «История» в настройках:

- **Сохранять историю на диск**. Выключено по умолчанию: тогда история хранится только в памяти до закрытия программы. Включено: каждая пара вопрос-ответ дописывается в `%APPDATA%\Polymath\history\ГГГГ-ММ-ДД.jsonl`, каждая строка зашифрована Windows DPAPI (прочитать её может только ваша учётная запись Windows).
- **Имя в истории**. Подпись ваших вопросов в экспорте. Пусто - имя пользователя Windows.
- **Хранить, дней**. Старые дни удаляются при запуске. 0 - хранить всегда.
- **Экспорт за** эту сессию, сегодня, 7 дней, 30 дней или всё время. «Экспорт в .txt» сохраняет файл в `Документы\Polymath`, «Копировать текстом» кладёт тот же текст в буфер обмена.
- **Очистить историю** удаляет файлы истории и записи текущей сессии (кнопку нужно нажать дважды).

Что записывается:

- чат: Q - ваш вопрос (с командой и отметкой о снимке экрана), A - ответ модели;
- Listen: Q - фраза собеседника и её перевод, A - предложенный вам ответ и его перевод (если ответ был нужен);
- Watch: ответы на задачи с экрана, пустые срабатывания не пишутся.

Пример экспорта:

```text
Polymath - история вопросов и ответов
Пользователь: Николай
Период: 2026-11-19 - 2026-11-19
Экспорт: 2026-11-19 15:10:02
Записей: 2

==== 2026-11-19 ====

[2026-11-19 14:02:11] Николай (чат, команда 1 Quick)
Q: Что такое идемпотентность?
A: Свойство операции давать тот же результат при повторном выполнении.

[2026-11-19 14:05:40] Собеседник -> Николай (Listen, en)
Q: What was your last project about?
   Перевод: О чём был ваш последний проект?
A: It was a payment service for online stores.
   Перевод: Это был платёжный сервис для интернет-магазинов.
```

Файл экспорта не зашифрован. Проводник и Блокнот, открытые кнопкой «Показать файл», видны при показе экрана.

## Приватность

- Ключи API хранятся зашифрованными средствами Windows (DPAPI через Electron safeStorage) в `%APPDATA%\Polymath\settings.json`.
- История по умолчанию хранится только в памяти и пропадает при закрытии. Сохранение на диск включается в настройках, файлы истории зашифрованы DPAPI.
- Файлы базы знаний хранятся у вас в `%APPDATA%\Polymath\knowledge` без шифрования, поиск по ним идёт на компьютере. Модели уходят только при вопросе: вся база, если она небольшая, иначе найденные фрагменты.
- Звук и снимки экрана отправляются только выбранному провайдеру (или резервному) и только когда включены Listen, Screenshot или Watch. При локальном whisper.cpp или Parakeet звук не покидает компьютер.
- Журнал ошибок: `%APPDATA%\Polymath\logs\app.log` (без текста разговоров).

## Запуск в фоне

Галочка «Запускать при входе в Windows» запускает Polymath скрытым. Панель вызывается сочетанием Ctrl+Alt+P. Вручную: `Polymath.exe --background`.

## Обновления

Установленный Polymath (из `Polymath-Setup`) через несколько секунд после запуска ищет новую версию. Без вашего согласия ничего не скачивается: на панели появляется «Доступна версия Polymath X» с кнопками «Обновить» и «Позже», а после загрузки - «Перезапустить и обновить». Polymath закрывается, ставится поверх старой версии и запускается снова, настройки, ключи и история остаются. Если включён значок в трее, в его меню есть пункт «Check for updates». Копия, запущенная из папки с исходниками, и портативная копия сами не обновляются.

Загрузка проверяется по SHA-512 из `latest.yml` релиза. Релиз без этого хеша отклоняется, файл, который не совпал, не устанавливается. Каждая сборка проверяет, что в `latest.yml` записан верный хеш. Установщик пока не подписан кодом, поэтому Windows SmartScreen всё равно может предупредить.

## Для разработчика

Нужен Node.js 20 или новее.

```powershell
npm install
```

```powershell
npm start
```

```powershell
npm test
```

```powershell
npm run dist
```

- `npm test` - модульные тесты (детектор фраз, WAV, разбор ответов, SSE, команды, настройки, клиент модели, история).
- `npm run dist` - установщик в `dist`, затем проверка, что в `latest.yml` записан верный SHA-512.
- `python scripts/make-installer-art.py` - заново рисует оформление установщика (`build/`: боковая картинка, шапка, значок) из `assets/icon.png`. Нужен Python с Pillow.
- `npm run capture-test` - встроенная проверка скрытия (результат в JSON).
- Переменная `POLYMATH_VISIBLE=1` отключает скрытие в режиме разработки, чтобы делать скриншоты интерфейса. В собранной программе она не действует.

Структура:

- `src/main` - главный процесс: окна, горячие клавиши, модель, распознавание речи, Listen, Watch;
- `src/renderer` - панель и окно настроек, захват системного звука;
- `src/shared` - общий код: детектор фраз, WAV, разбор текста, SSE, переводы интерфейса;
- `scripts` - установка whisper.cpp и Parakeet, проверка скрытия и проверка `latest.yml`;
- `tests` - тесты.
