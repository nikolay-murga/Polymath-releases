# Polymath для Windows

[English](README.en.md) | [Русский](README.ru.md) | [Українська](README.uk.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Français](README.fr.md) | [Türkçe](README.tr.md) | [中文](README.zh.md)

Небольшая панель-помощник для разговоров и встреч. Она слушает собеседника и переводит его речь на ваш язык, предлагает ответ на языке разговора, решает задачу с экрана и отвечает на любой вопрос в чате.

**Панель видите только вы.** Её не видно, когда вы показываете экран в Zoom, Teams, Meet, Discord или OBS, а также на скриншотах и в записях экрана.

## Возможности

- **Слушать**. Слушает звук компьютера (голос собеседника в звонке), распознает фразы, показывает перевод на ваш родной язык и, когда обращаются к вам, готовый ответ на языке разговора с переводом. Нажмите на ответ, чтобы скопировать его. Режим «Только когда нужен ответ» показывает только те реплики, на которые стоит ответить.
- **Экран**. Скриншот отправляется модели: решение задачи, ответ на тестовый вопрос, разбор кода.
- **Наблюдать**. Следит за экраном и отвечает, когда на нем появляется новый вопрос или задача. Выключается сам через 10 минут.
- **Чат**. Обычные вопросы. Цифра в начале сообщения выбирает команду: `1` Быстро (короткий ответ, быстрая модель), `3` Ответ (ответ на последний услышанный вопрос с учетом разговора), `5` Перевод.
- Модель видит последние фразы разговора, поэтому в чате можно спросить: «как ответить на их последний вопрос?».
- **База знаний**. Ваши собственные файлы `.txt` и `.md` с готовыми ответами на частые вопросы. Подходящий ответ ищется на компьютере, без интернета, и показывается сразу, пока модель еще думает.
- **Свои команды**. Добавляйте собственные команды с цифрами, со своими инструкциями, моделью и настройками экрана или звука.
- **История и экспорт**. По желанию сохранение разговоров в зашифрованном виде и экспорт в текстовый файл.

## Установка

В каждом релизе опубликованы два готовых файла:

- `Polymath-Setup-<версия>.exe` - установщик, язык выбирается по языку Windows, поддерживается 22 языка. Можно выбрать папку, права администратора не нужны, ярлыки появляются на рабочем столе и в меню «Пуск», программа запускается сразу после установки.

Windows SmartScreen может предупредить о неизвестном издателе, потому что файл пока не подписан. Нажмите «Подробнее» и затем «Всё равно запустить».

Требования: Windows 10 версии 2004 (май 2020) или новее, либо Windows 11. На более старых системах скрытие от демонстрации экрана не работает.

Обновления: установленная копия проверяет эту страницу на новые версии через несколько секунд после запуска. Когда появляется более новая версия, программа показывает карточку и загружает обновление только с вашего согласия. Обновление ставится в ту же папку, и программа запускается снова.

## Первый запуск

1. Откройте настройки (шестеренка на панели).
2. Выберите провайдера модели, вставьте ключ API и нажмите «Сохранить ключ». Ссылка «Получить ключ» открывает страницу провайдера.
3. Нажмите «Проверить соединение». Появится список доступных моделей, нажатие на модель ставит ее в поле.
4. Укажите родной язык. В разделе «База знаний» кратко опишите себя в поле «О вас» (работа, опыт). Модель использует это в ответах.
5. Нажмите «Сохранить» (или Ctrl+S).

### Провайдеры

| Провайдер                       | Модель по умолчанию      | Картинки (Экран/Наблюдать) | Звук напрямую |
| ------------------------------- | ------------------------ | -------------------------- | ------------- |
| Google Gemini                   | gemini-flash-lite-latest | да                         | да            |
| OpenAI                          | gpt-5-mini               | да                         | нет           |
| Anthropic Claude                | claude-sonnet-5-5        | да                         | нет           |
| OpenRouter                      | openrouter/auto          | да                         | нет           |
| Groq                            | openai/gpt-oss-120b      | нет                        | нет           |
| Mistral                         | mistral-medium-latest    | да                         | нет           |
| Ollama (локально)               | llama3.2                 | нет                        | нет           |
| Свой (совместимый с OpenAI)     | любая                    | зависит от модели          | нет           |

Провайдеры переименовывают свои модели. Если модель не найдена, нажмите «Проверить соединение» и выберите модель из списка.

«Быстрая модель» используется командами «Быстро» и «Перевод». Поле можно оставить пустым, тогда используется основная модель.

Если модель отвечает 503 (перегружена) или 429 (закончилась квота), программа сразу спрашивает вторую модель из пары.

### Резервная модель

В разделе «Резервная модель» настроек задается другой провайдер, которого программа спрашивает, когда обе основные модели отвечают 503 или 429. Например, Anthropic Claude (по умолчанию `claude-haiku-5-5`, быстрая модель). Резервный ключ хранится отдельно. Если его нет, используется ключ того же провайдера из раздела «Модель». Резерв пропускается, если он не может прочитать отправляемое, например картинку с экрана (Экран/Наблюдать) или звук.

## Распознавание речи (для «Слушать»)

В настройках «Распознавание речи» есть четыре варианта:

1. **Через модель** (по умолчанию). Фраза уходит прямо в модель чата. Работает с Google Gemini, тем же ключом.
2. **Облачный Whisper API**. OpenAI (`whisper-1`, `gpt-4o-mini-transcribe`), Groq (`whisper-large-v3-turbo`, быстро и дешево) или ваш сервер, совместимый с OpenAI. Ключ распознавания хранится отдельно от ключа модели.
3. **Локально (whisper.cpp)**. Звук никогда не покидает компьютер. Устанавливается одной командой, файлы попадают в `%APPDATA%\Polymath\whisper`. Затем выберите «Локально» и нажмите «Проверить распознавание». По умолчанию используется малая модель (466 МБ). Другие размеры и ускорение на видеокартах NVIDIA доступны как параметры скрипта установки.
4. **Локально (NVIDIA Parakeet)**. Тоже на этом компьютере, быстрее whisper.cpp на процессоре и обычно точнее. Модель знает 25 европейских языков (английский, русский, украинский, немецкий, французский, испанский и другие), но не турецкий и китайский. Кнопка «Скачать Parakeet» в настройках ставит модель на место. Всего около 520 МБ. Затем выберите «Локально (NVIDIA Parakeet)» и нажмите «Проверить распознавание». Первая фраза после паузы ждет 7-10 секунд, пока модель загрузится, а следующие занимают меньше секунды. Если речи нет 10 минут, сервер останавливается и освобождает память.

При первом запуске на новом компьютере панель один раз спрашивает, как распознавать речь: через Gemini (ничего скачивать не нужно) или с Parakeet на этом компьютере (программа скачает около 520 МБ, с индикатором хода и кнопкой отмены). Ответ можно поменять позже в настройках.

Кнопка «Проверить распознавание» работает для всех четырех вариантов.

## Как пользоваться

| Действие                          | Сочетание                      |
| --------------------------------- | ------------------------------ |
| Показать / скрыть панель          | `Ctrl` + `Alt` + `P`           |
| Решить задачу с экрана            | `Ctrl` + `Alt` + `2`           |
| Наблюдать за экраном (вкл/выкл)   | `Ctrl` + `Alt` + `4`           |
| Слушать звонок (вкл/выкл)         | `Ctrl` + `Alt` + `7`           |
| Сквозной клик по панели (вкл/выкл)| `Ctrl` + `Alt` + `T`           |
| Отправить                         | `Enter`                        |
| Новая строка                      | `Shift` + `Enter`              |
| Остановить ответ                  | `Ctrl` + `.` или кнопка `■`    |
| Новый разговор                    | `Ctrl` + `N` или кнопка `+`    |
| Предыдущий запрос                 | `↑` / `↓` в пустом поле        |
| Скрыть панель                     | `Esc`                          |

Сочетания меняются в настройках: нажмите на поле и нажмите нужную комбинацию. Если её уже использует другая программа, панель это сообщит.

Панель перетаскивается за заголовок, ее место запоминается. Ширина, прозрачность и размер шрифта настраиваются.

### Вид и мышь

Раздел «Интерфейс» в настройках:

- **Тема**: темная (графит, по умолчанию) или светлая (слоновая кость).
- **Прозрачность панели**: вся панель вместе с текстом (30-100%).
- **Прозрачность фона**: только фон панели, текст остается четким (20-100%).
- **Сквозной клик по панели**: клики проходят через панель-помощник к окну под ней. Двигать панель или нажимать на нее мышью нельзя, но клавиатура и сочетания работают. Включается и выключается сочетанием `Ctrl` + `Alt` + `T`, а в заголовке панели появляется отметка «сквозной клик». Окно настроек всегда обычное.
- **Нажимать кнопки наведением**: положите курсор на кнопку панели (по умолчанию 3 секунды, можно от 1,5 до 5) и она нажмется сама. Под кнопкой заполняется полоска. Работает и в режиме сквозного клика.

«Слушать» захватывает звук всей системы. Используйте наушники: тогда записывается только собеседник, а не ваш голос.

## Свои команды

Команды с цифрами хранятся в `%APPDATA%\Polymath\commands.json` (кнопка «Открыть commands.json» в настройках). Файл перечитывается при каждом вызове, перезапуск не нужен. Пример:

```json
{
  "1": {
    "name": "Интервью",
    "instructions": "Отвечай как старший Java-разработчик на собеседовании. Отвечай на языке {conversation_language}, затем дай короткий перевод на {native}.",
    "model": "main"
  }
}
```

Поля: `name`, `instructions` (обязательно), `model` (`main` или `small`), `screen: true` (прикладывать скриншот), `watch: true` (наблюдать за экраном), `listen: true` (включать «Слушать»). Подстановки: `{native}` - ваш язык, `{conversation_language}` - язык разговора.

## Скрытие от демонстрации экрана

Окна создаются с помощью механизма Windows, который исключает их из захвата (`WDA_EXCLUDEFROMCAPTURE`). При захвате экрана вместо панели видно то, что под ней. Zoom, Teams, Google Meet в браузере, Discord, OBS, «Ножницы», PrintScreen и Xbox Game Bar этот механизм учитывают.

Также:

- нет кнопки на панели задач и записи в Alt+Tab;
- значок в трее по умолчанию выключен (трей виден, когда показывают весь экран);
- никаких системных всплывающих окон: подсказки, списки и меню рисуются внутри панели, контекстное меню отключено.

Ограничения:

- Скрытие не защищает от камеры, направленной на монитор, и от аппаратного HDMI-захвата.
- Если вы показываете **окно** программы (а не весь экран) и панель лежит поверх него, собеседник видит то, что под панелью. Это ожидаемо.
- На Windows старше 10 версии 2004 вместо панели в захвате видно черный прямоугольник.
- Открытые ссылки и файлы (commands.json, папка данных) открываются в обычных программах и видны при демонстрации экрана.

## База знаний

Раздел «База знаний» в настройках:

- **О вас**: общая информация о вас. Модель использует ее в каждом ответе.
- **Файлы**: кнопка «Добавить файлы» или перетаскивание файлов `.txt` и `.md` в раздел. Файлы копируются в `%APPDATA%\Polymath\knowledge` (кнопка «Открыть папку»). Их можно редактировать прямо там, программа подхватит изменения сама. Файл с тем же именем заменяется. Ограничение: 2 МБ на файл, кодировки UTF-8, UTF-16 или Windows-1251.
- **Использовать базу в ответах**: включается, как только в базе появился файл.
- **Сразу показывать совпадение из базы, до ответа модели**: то же самое.

Как это работает. На вопрос в чате и на каждую фразу собеседника в «Слушать» программа сначала ищет ответ в ваших файлах, без интернета и без модели. Совпадение появляется сразу синим блоком «Из базы знаний» над ответом модели, рядом есть кнопка «Копировать». Одновременно модель получает эти данные (всю базу, если она небольшая, иначе найденные части) и отвечает с их опорой. Поиск понимает разные формы слов. Локальный поиск не находит вопрос, написанный на другом языке, но модель все равно отвечает по базе.

Три способа записать файлы:

```markdown
# Какую зарплату вы ожидаете?
От 5 000 USD на руки, готов обсуждать.

# Почему вы уходите с текущей работы?
Хочу больше работы с архитектурой.
```

```text
Q: Какой срок отработки?
A: Две недели.
```

Или просто абзацы, разделенные пустой строкой. Короткая первая строка абзаца становится его темой.

## История и экспорт

Раздел «История» в настройках:

- **Сохранять историю на диск**. По умолчанию выключено: история живет только в памяти до закрытия программы. Когда включено, каждый вопрос и ответ дописываются в файл за день в `%APPDATA%\Polymath\history`, и каждая строка шифруется через Windows DPAPI, поэтому читать ее может только ваша учетная запись Windows.
- **Имя в истории**. Подписывает ваши вопросы в экспорте. Пусто означает имя пользователя Windows.
- **Хранить, дней**. Старые дни удаляются при запуске. 0 означает хранить все.
- **Экспорт** за этот сеанс, за сегодня, 7 дней, 30 дней или за все время. «Экспорт в .txt» сохраняет файл в `Документы\Polymath`, «Копировать как текст» кладет тот же текст в буфер обмена.
- **Очистить историю** удаляет файлы истории и записи этого сеанса (кнопку нужно нажать дважды).

Что записывается:

- чат: вопрос (с командой и отметкой о скриншоте) и ответ модели;
- «Слушать»: фраза собеседника и ее перевод, а также предложенный ответ и его перевод, если ответ был нужен;
- «Наблюдать»: ответы на задачи с экрана. Пустые запуски не записываются.

Файл экспорта не зашифрован. Проводник и Блокнот, открытые кнопкой «Показать файл», видны при демонстрации экрана.

## Конфиденциальность

- Ключи API хранятся зашифрованными средствами Windows (DPAPI) в `%APPDATA%\Polymath\settings.json`.
- По умолчанию история только в памяти и пропадает при закрытии программы. Сохранение на диск включается в настройках, а файлы истории шифруются через DPAPI.
- Файлы базы знаний хранятся без шифрования в `%APPDATA%\Polymath\knowledge` и ищутся на компьютере. В модель они уходят только вместе с вопросом: вся база, если она небольшая, иначе найденные части.
- Звук и скриншоты уходят только выбранному провайдеру (или резервному) и только пока включены «Слушать», «Экран» или «Наблюдать». С локальными whisper.cpp или Parakeet звук никогда не покидает компьютер.
- Журнал ошибок: `%APPDATA%\Polymath\logs\app.log`. В нем нет текста разговоров.

## Запуск в фоне

Галочка «Запускать при входе в Windows» запускает Polymath скрытым. Вызвать панель можно сочетанием `Ctrl` + `Alt` + `P`.

## Требования и ограничения

- Windows 10 версии 2004 или новее, либо Windows 11.
- Интернет нужен для облачных моделей. Локальное распознавание речи после установки работает без сети.
- Ключ хотя бы одного провайдера модели. Ключи ваши, оплачивает их провайдер.
