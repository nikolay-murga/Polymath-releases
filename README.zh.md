# Windows 版 Polymath

[English](README.en.md) | [Русский](README.ru.md) | [Українська](README.uk.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Français](README.fr.md) | [Türkçe](README.tr.md) | [中文](README.zh.md)

一个用于对话和会议的小型辅助工具栏。它会聆听对方的讲话并翻译成您的语言，用对话的语言给出回复建议，解答屏幕上的任务，并在聊天中回答任何问题。

**只有您能看到这个工具栏。** 在 Zoom、Teams、Meet、Discord 或 OBS 中共享屏幕时，它不会出现，在截图和屏幕录像中也不会出现。

## 功能

- **聆听**。聆听电脑的声音（通话中对方的声音），识别语句，显示翻译成您母语的内容；当有人向您提问时，显示对话语言的现成回复及其翻译。点击回复即可复制。“仅在需要回复时”模式只显示您需要回答的语句。
- **屏幕**。将截图发送给模型：解答任务、回答测试题、审查代码。
- **观察**。监视屏幕，当屏幕上出现新问题或任务时作答。10 分钟后自动关闭。
- **聊天**。普通提问。开头的数字用于选择命令：`1` 快速（简短回答，使用快速模型），`3` 回答（针对最近听到的问题作答，并考虑整段对话），`5` 翻译。
- 模型能看到对话的最新语句，因此您可以在聊天中问：“我该怎样回答他们最后的问题？”。
- **知识库**。您自己的 `.txt` 和 `.md` 文件，内含常见问题的现成答案。匹配的答案在电脑上查找，无需联网，并在模型仍在作答时立即显示。
- **自定义命令**。使用您自己的说明、模型以及屏幕或声音设置，添加带数字的自定义命令。
- **历史记录与导出**。可选择加密保存对话，并导出为文本文件。

## 安装

每个版本发布两个现成文件：

- `Polymath-Setup-<版本>.exe` - 安装程序，根据 Windows 语言显示，支持 22 种语言。可以选择文件夹，无需管理员权限，快捷方式会创建在桌面和“开始”菜单中，安装完成后程序自动启动。

由于文件尚未签名，Windows SmartScreen 可能会提示发布者未知。点击“更多信息”，然后点击“仍要运行”。

系统要求：Windows 10 2004 版（2020 年 5 月）或更高版本，或 Windows 11。在较旧的系统上，屏幕共享时隐藏的功能无法使用。

更新：已安装的副本会在启动后几秒钟检查此页面上是否有新版本。出现更新版本时，程序会显示提示卡片，并且只有在您同意后才会下载更新。更新会安装到同一文件夹，然后程序重新启动。

## 首次启动

1. 打开设置（工具栏上的齿轮图标）。
2. 选择模型提供商，粘贴 API 密钥，然后点击“保存密钥”。“获取密钥”链接会打开提供商的页面。
3. 点击“测试连接”。会出现可用模型列表，点击某个模型即可将其填入输入框。
4. 设置您的母语。在“知识库”部分的“关于您”中简要描述自己（职业、经验）。模型会在回答中使用这些信息。
5. 点击“保存”（或按 Ctrl+S）。

### 提供商

| 提供商                        | 默认模型                 | 图片（屏幕/观察） | 直接处理声音 |
| ----------------------------- | ------------------------ | ----------------- | ------------ |
| Google Gemini                 | gemini-flash-lite-latest | 是                | 是           |
| OpenAI                        | gpt-5-mini               | 是                | 否           |
| Anthropic Claude              | claude-sonnet-5-5        | 是                | 否           |
| OpenRouter                    | openrouter/auto          | 是                | 否           |
| Groq                          | openai/gpt-oss-120b      | 否                | 否           |
| Mistral                       | mistral-medium-latest    | 是                | 否           |
| Ollama（本地）                | llama3.2                 | 否                | 否           |
| 自定义（兼容 OpenAI）         | 任意                     | 取决于模型        | 否           |

提供商会更改模型名称。如果找不到某个模型，请点击“测试连接”并从列表中选择。

“快速模型”由“快速”和“翻译”命令使用。可以留空，此时使用主模型。

当某个模型返回 503（过载）或 429（配额用完）时，程序会立即询问这一对模型中的另一个。

### 备用模型

设置中的“备用模型”部分指定另一个提供商，当上面两个模型都返回 503 或 429 时，程序会询问它。例如 Anthropic Claude（默认为 `claude-haiku-5-5`，一个快速模型）。备用密钥单独保存。如果没有填写，则使用“模型”部分中同一提供商的密钥。如果备用模型无法读取所发送的内容（例如屏幕图片（屏幕/观察）或声音），则会跳过。

## 语音识别（用于“聆听”）

“语音识别”设置提供四种引擎：

1. **通过模型**（默认）。语句直接发送给聊天模型。使用同一个 Google Gemini 密钥即可工作。
2. **云端 Whisper API**。OpenAI（`whisper-1`、`gpt-4o-mini-transcribe`）、Groq（`whisper-large-v3-turbo`，快速且便宜），或您自己的兼容 OpenAI 的服务器。识别密钥与模型密钥分开保存。
3. **本地（whisper.cpp）**。声音永远不会离开电脑。通过一条命令安装，文件保存在 `%APPDATA%\Polymath\whisper`。然后选择“本地”并点击“测试识别”。默认使用小型模型（466 MB）。其他规格以及 NVIDIA 显卡加速可作为安装脚本的选项使用。
4. **本地（NVIDIA Parakeet）**。同样在这台电脑上运行，在处理器上比 whisper.cpp 更快，通常也更准确。该模型支持 25 种欧洲语言（英语、俄语、乌克兰语、德语、法语、西班牙语等），但不支持土耳其语和中文。设置中的“下载 Parakeet”按钮会将其安装到位，总共约 520 MB。然后选择“本地（NVIDIA Parakeet）”并点击“测试识别”。停顿后的第一句话需要等待 7-10 秒以加载模型，之后的语句不到一秒即可完成。如果 10 分钟没有语音，服务器会停止并释放内存。

在新电脑上首次启动时，工具栏会询问一次如何识别语音：通过 Gemini（无需下载任何内容），或在这台电脑上使用 Parakeet（程序会下载约 520 MB，并显示进度和取消按钮）。之后可以在设置中更改。

“测试识别”按钮适用于所有四种引擎。

通过标题栏拖动工具栏，其位置会被记住。宽度、透明度和字体大小均可调整。

### 外观与鼠标

设置中的“界面”部分：

- **主题**：深色（石墨色，默认）或浅色（象牙色）。
- **工具栏透明度**：整个工具栏（包括文字）（30-100%）。
- **背景透明度**：仅工具栏背景，文字保持清晰（20-100%）。
- **穿透点击工具栏**：点击会穿过辅助工具栏，作用于下方的窗口。此时工具栏无法用鼠标移动或点击，但键盘和快捷键仍然有效。使用 `Ctrl` + `Alt` + `T` 切换，工具栏标题会显示“穿透点击”标记。设置窗口始终是普通窗口。
- **悬停即按按钮**：将光标放在工具栏按钮上（默认 3 秒，可设置为 1.5 到 5 秒），按钮会自动按下。按钮下方会出现填充进度条。穿透点击模式下同样有效。

“聆听”会捕获整个系统的声音。请使用耳机：这样录制的只有对方的声音，而不会录到您自己的声音。

## 自定义命令

带数字的命令保存在 `%APPDATA%\Polymath\commands.json` 中（设置中的“打开 commands.json”按钮）。每次调用时都会重新读取该文件，无需重启。示例：

```json
{
  "1": {
    "name": "面试",
    "instructions": "像资深 Java 开发者一样回答面试问题。用 {conversation_language} 回答，然后给出一段简短的 {native} 译文。",
    "model": "main"
  }
}
```

字段：`name`、`instructions`（必填）、`model`（`main` 或 `small`）、`screen: true`（附加截图）、`watch: true`（观察屏幕）、`listen: true`（开启“聆听”）。占位符：`{native}` 是您的语言，`{conversation_language}` 是对话的语言。

## 屏幕共享时的隐藏

窗口通过 Windows 机制创建，该机制会将其排除在屏幕捕获之外（`WDA_EXCLUDEFROMCAPTURE`）。捕获屏幕时，显示的是窗口下方的内容。Zoom、Teams、浏览器中的 Google Meet、Discord、OBS、截图工具、PrintScreen 和 Xbox Game Bar 都会遵循这一机制。

此外：

- 任务栏上没有按钮，Alt+Tab 中也没有条目；
- 托盘图标默认关闭（共享整个屏幕时托盘可见）；
- 没有系统弹窗：提示、列表和菜单都在工具栏内绘制，右键菜单已关闭。

局限性：

- 隐藏功能无法防范对准显示器的摄像头或硬件 HDMI 采集。
- 如果您共享的是程序的**窗口**（而不是整个屏幕），并且工具栏位于它上面，对方会看到工具栏下方的内容。这是正常现象。
- 在 Windows 10 2004 版之前的系统上，捕获结果中工具栏的位置会显示为黑色矩形。
- 打开的链接和文件（commands.json、数据文件夹）会在普通程序中打开，共享屏幕时可见。

## 知识库

设置中的“知识库”部分：

- **关于您**：关于您的一般信息。模型在每次回答中都会使用它。
- **文件**：点击“添加文件”按钮，或将 `.txt` 和 `.md` 文件拖放到该部分。文件会被复制到 `%APPDATA%\Polymath\knowledge`（“打开文件夹”按钮）。您可以直接在那里编辑，程序会自动识别更改。同名文件会被替换。限制为每个文件 2 MB，编码为 UTF-8、UTF-16 或 Windows-1251。
- **在回答中使用知识库**：知识库中有文件后即可开启。
- **在模型回答之前立即显示知识库中的匹配内容**：同上。

工作原理。对于聊天中的问题，以及“聆听”中对方的每一句话，程序会先在您的文件中查找答案，无需联网，也无需模型。匹配结果会立即以蓝色“来自知识库”块的形式显示在模型回答上方，旁边有“复制”按钮。同时，模型会获得这些数据（知识库较小时为整个知识库，否则为匹配的部分），并基于这些内容作答。搜索能够识别词语的不同形式。本地搜索无法找到用其他语言写的问题，但模型仍会根据知识库作答。

编写文件的三种方式：

```markdown
# 您期望的薪资是多少？
税后 5000 美元起，可以商量。

# 您为什么要离开现在的工作？
我想从事更多架构方面的工作。
```

```text
Q: 您的通知期是多久？
A: 两周。
```

或者直接用空行分隔的段落。段落的第一行如果较短，则作为其主题。

## 历史记录与导出

设置中的“历史记录”部分：

- **将历史记录保存到磁盘**。默认关闭：此时历史记录仅保存在内存中，直到程序关闭。开启后，每个问题和回答都会追加到 `%APPDATA%\Polymath\history` 中按日期命名的文件，每一行都使用 Windows DPAPI 加密，因此只有您的 Windows 账户可以读取。
- **历史记录中的名称**。在导出内容中标记您的问题。留空则使用 Windows 用户名。
- **保留天数**。程序启动时会删除较早的记录。0 表示全部保留。
- **导出**本次会话、今天、7 天、30 天或全部时间的记录。“导出为 .txt”会将文件保存到 `文档\Polymath`，“复制为文本”会将相同文本放入剪贴板。
- **清除历史记录**会删除历史文件和本次会话的记录（需要按两次按钮）。

记录的内容：

- 聊天：问题（包括命令和截图标记）以及模型的回答；
- 聆听：对方的语句及其译文，以及需要回复时建议的回复及其译文；
- 观察：对屏幕任务的回答。空的运行结果不会被记录。

导出文件未加密。通过“显示文件”按钮打开的资源管理器和记事本，在共享屏幕时是可见的。

## 隐私

- API 密钥由 Windows 加密保存（DPAPI），位于 `%APPDATA%\Polymath\settings.json`。
- 默认情况下，历史记录仅保存在内存中，程序关闭后即消失。在设置中开启磁盘保存后，历史文件会使用 DPAPI 加密。
- 知识库文件以未加密形式保存在 `%APPDATA%\Polymath\knowledge` 中，并在您的电脑上搜索。它们只会随问题一起发送给模型：知识库较小时发送整个知识库，否则只发送匹配的部分。
- 声音和截图只会发送给所选提供商（或备用提供商），并且仅在“聆听”、“屏幕”或“观察”开启期间发送。使用本地 whisper.cpp 或 Parakeet 时，声音永远不会离开电脑。
- 错误日志位于 `%APPDATA%\Polymath\logs\app.log`，不包含对话文本。

## 后台运行

“开机时启动”选项会以隐藏方式启动 Polymath。使用 `Ctrl` + `Alt` + `P` 调出工具栏。

## 系统要求与限制

- Windows 10 2004 版或更高版本，或 Windows 11。
- 云端模型需要联网。安装后，本地语音识别无需网络即可工作。
- 至少一个模型提供商的密钥。密钥属于您，费用由提供商收取。
